# Perfect Dental

Многостраничный сайт стоматологии Perfect Dental в Астане. Публичные страницы статически пререндерятся для быстрой загрузки и корректной индексации, а заявки отправляются через PHP API в Telegram.

## Локальная разработка

```bash
npm install
npm run dev
```

Проверка перед публикацией:

```bash
npm run lint
npm run build
```

Готовая статическая сборка находится в `build/client`.

## Публикация на казахстанском хостинге

1. Зарегистрировать `perfectdental.kz` на аккаунт клиента.
2. Создать PHP-хостинг с HTTPS и поддержкой Apache `mod_rewrite`, PHP 8.1+, `mbstring` и `curl`.
3. Загрузить содержимое `build/client` в публичный каталог сайта.
4. Задать `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` на уровне панели хостинга или серверной конфигурации. Не помещать секреты в публичный каталог.
5. Проверить отправку формы, HTTPS, редирект с `www`, страницы `/robots.txt` и `/sitemap.xml`.
6. Добавить домен в Google Search Console и один раз отправить `https://perfectdental.kz/sitemap.xml`.

Если PHP API размещается отдельно от preview-сайта, адрес можно задать переменной `VITE_APPOINTMENT_API_URL` до сборки.

## Что потребуется от клиники

- реальные фотографии и краткие анкеты врачей;
- подтверждённые фотографии клинических работ и согласия пациентов;
- подтверждение точных моделей 3D-диагностики и внутриротового сканера;
- Telegram-чат получателя заявок;
- аккаунт клиента для регистрации домена и оплаты хостинга.

Банковские реквизиты, вымышленные цены, гарантии, рейтинги и неподтверждённые достижения на сайте не публикуются.
